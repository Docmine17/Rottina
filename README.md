Um aplicativo Android para rastreamento e gerenciamento de rotinas desenvolvido com **Kotlin** e **Jetpack Compose**. 

O destaque do projeto é um relógio visual interativo que permite aos usuários visualizar, organizar e arrastar suas tarefas diárias ao longo do dia, com suporte elegante tanto para o formato de 12 horas (AM/PM) quanto para o de 24 horas. Ele utiliza o Room Database para garantir a persistência local dos hábitos e tarefas.
